# ZOE Esquadrias 🌳

Site institucional da **ZOE Esquadrias** — projetos em vidro e alumínio de alto padrão.

## Tecnologias

- HTML5 semântico
- TailwindCSS (CDN)
- JavaScript Vanilla (ES6+)
- Design Mobile-First

## Funcionalidades

- Menu lateral (sidebar) interativo com estados expandido/recolhido
- Carrossel de projetos com swipe nativo
- Seção de Dicas ZOE com acordeão (expand/collapse)
- Formulário de contato responsivo
- Animação de rotação 360° orientada por scroll
- Paleta de cores: Preto · Dourado · Branco

## Deploy

Projeto hospedado na **Vercel** com deploy automático a cada push na branch `main`.

## Estrutura

```
ZOE/
├── index.html       # Página principal (Home)
├── artigos.html     # Página dedicada de artigos e guias técnicos
├── logo.jpg         # Logotipo da marca
├── images/          # Galeria de fotos reais dos projetos executados
├── .gitignore       # Arquivos ignorados no versionamento
└── README.md        # Documentação
```
